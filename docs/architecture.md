# Architecture

One Go executable provides `api`, `worker`, and `migrate` commands, plus internal
bounded processing commands. HTTP uses net/http; PostgreSQL is the only durable
queue. govips wraps native libvips; this is **not** a dependency-free static binary.
The deployment image supplies libvips, JPEG, PNG, WebP, HEIF/AV1, and Little CMS.

## Boundaries and invariants

- Configuration resolves named profiles before acceptance. Jobs snapshot the
  profile and pipeline version. Operators, not API callers, select codec options.
- Uploads stream to private staging, with byte limits even without Content-Length.
  Validation and native processing run in deadline-controlled subprocesses.
- Original bytes are immutable. Generated IDs, never client filenames, form paths.
- Workers claim with PostgreSQL row locking, expiring leases, and ownership
  tokens. Heartbeats extend leases; stale attempts cannot publish.
- Encoding does not hold a database transaction. Every attempt has private staging.
  Only a complete manifest is published. Download handlers consult committed
  database records, so filesystem presence alone does not grant visibility.
- Deletion removes database visibility before file reclamation. Lease fencing
  prevents publication after deletion. Reconciliation removes unreferenced files
  after a grace period; failed file deletion is recoverable.
- Filesystem rename/fsync and database commit are not a distributed transaction.
  Write originals before accepting their database references; move complete
  attempt directories before committing manifests. Crash-created orphans are
  reclaimed, never mistaken for successful jobs. Reconciliation runs on worker
  startup and hourly with a 48-hour grace period.

## Resource model

Defaults: 20 MiB uploaded file, 40 million decoded pixels, dimension 20,000,
17 outputs, 200 MiB aggregate generated bytes, one worker slot, two libvips
threads per processing child, and a 120-second processing deadline.
Container memory/CPU/PID limits provide an additional deployment boundary.
Encoded buffers can exist before their size is checked; output-byte limits are
publication limits, not native allocation limits. Do not equate cancelled
request contexts with interruptible native encoding.

Profiles and exact environment names are documented in the README. A single
worker container is the default; increasing replicas increases total concurrency.
Tune slots together with libvips threading and memory measurements.
Each API instance separately permits at most `WORKER_CONCURRENCY` concurrent
upload validations and rejects excess requests with 503. Upload bodies have a
60-second read deadline. Readiness serializes and caches native probes for
30 seconds; it does not prove that a worker is running.

## Color and formats

Apply EXIF orientation before resizing. Use embedded ICC profiles for conversion
to sRGB; reject unprofiled CMYK and unsupported interpretations. For unprofiled
ordinary RGB/gray, assume sRGB. Alpha survives PNG/WebP/AVIF. PNG optimization is
lossless, not palette quantization. Every output derives directly from the
normalized source, never another lossy output.

JPEG uses quality 85 and fixed optimized Huffman coding (no invented effort
scale); PNG uses lossless compression level 6 without a palette. WebP uses
quality 80/effort 4 and AVIF quality 50/effort 4. Equal numeric qualities across
codecs do not imply equal visual quality. JPEG recompression may lose detail.

Each registered output declares extension, MIME, transparency, and available
encoder. Startup performs an encode/decode smoke check for required formats.
An unavailable required encoder is fatal. New formats require reviewed releases,
explicit configuration, structural tests, visual/quality evaluation, performance
measurements, and client compatibility review. Encoder support is not browser
compatibility.

## Security and operations

API keys remain server-side and are compared in constant time.
Originals always require authentication. Variants require authentication unless
PUBLIC_VARIANTS is explicitly enabled; opaque URLs are not access control.
CORS is off unless an explicit origin allowlist is configured. Logs must not
include secrets, image bytes, filesystem paths, or sensitive image metadata.
Back up PostgreSQL and the image volume together; restoring either alone is
insufficient. Public caches can outlive deletion.
